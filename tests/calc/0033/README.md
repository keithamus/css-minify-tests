# Resolve with correct order of operations in division with parentheses

In this example `(100% - 5em) / 2` can be represented as this fraction:

<math display="block">
  <mfrac>
    <mrow>
      <mn>100%</mn>
      <mo>−</mo>
      <mn>5em</mn>
    </mrow>
    <mn>2</mn>
  </mfrac>
</math>

Which allows dividing each part of the numerator by the denominator, like so:
`(100% / 2) - (5em / 2)`. Which can be resolved to `50% - 2.5em`.
