# `flex` shorthand with grow `2`, shrink `1`, and basis `0%`

A unitless number as the only `flex` argument will be used as the `flex-grow`,
with the `flex-shrink` assumed to be `1` and the `flex-basis` assumed as `0%`.
`flex:2 1 0%` is the same as `flex:2`.

* https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/flex
