# `flex` shorthand with grow `0`, shrink `0`, and basis `auto`

A `flex` shorthand with `none` as the only argument will assume a `flex-grow`
of `0`,  a `flex-shrink` of `0`, and a `flex-basis` of `auto`. `flex:0 0 auto`
is the same as `flex:none`.

* https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/flex
