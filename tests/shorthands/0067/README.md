# `flex` shorthand with grow `2`, shrink `2`, and basis `0%`

A `flex` shorthand with two unitless numbers will assume they are the
`flex-grow` and `flex-shrink` with a `flex-basis` of `0%`. `flex:2 2 0%` is the
same as `flex:2 2`.

* https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/flex
